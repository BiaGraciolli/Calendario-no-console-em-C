# Calendario no console em C
Script em desenvolvimento em linguagem C para exibição de calendário anual, com organização dos meses, dias da semana e identificação de anos bissextos, com possibilidade de anotações. 

# Funcionalidades Atuais
Calendário completo: exibe os 12 meses do ano informado, organizados de acordo com os dias da semana.
Calendário mensal: permite visualizar o calendário de um mês específico.
Adicionar anotações: permite registrar informações em uma data específica, com limite de 100 caracteres por anotação.
Consultar anotações: exibe todas as anotações registradas, organizadas por mês e dia.

# Conceitos aplicados
Variáveis e tipos de dados;
Vetores e matrizes;
Estruturas condicionais (if, else e switch);
Estruturas de repetição (for, while e do-while);
Funções;
Manipulação de strings;
Entrada e saída de dados (printf, scanf, getchar e fgets).

# Observações
O ano é informado pelo usuário no início da execução.
As anotações são armazenadas em memória durante a execução do programa.
Ao encerrar o programa, as anotações não são preservadas.

# Como executar
É necessário ter um compilador da linguagem C instalado.
Clone este repositório:
`git clone https://github.com/BiaGraciolli/Calendario-no-console-em-C/`
Compile o arquivo:
`gcc calendario.c -o calendario`
Execute o programa:
# LINUX
`./calendario`
# Windows:
`.\calendario.exe`
