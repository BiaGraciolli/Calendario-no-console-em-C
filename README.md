# Calendario no console em C
Script em desenvolvimento em linguagem C para exibição de calendário anual, com organização dos meses, dias da semana e identificação de anos bissextos, com possibilidade de anotações. 

**Funcionalidades Atuais**<br>
Calendário completo: exibe os 12 meses do ano informado, organizados de acordo com os dias da semana.<br>
Calendário mensal: permite visualizar o calendário de um mês específico.<br>
Adicionar anotações: permite registrar informações em uma data específica, com limite de 100 caracteres por anotação.<br>
Consultar anotações: exibe todas as anotações registradas, organizadas por mês e dia.<br>

**Conceitos aplicados**<br>
Variáveis e tipos de dados;<br>
Vetores e matrizes;<br>
Estruturas condicionais (if, else e switch);<br>
Estruturas de repetição (for, while e do-while);<br>
Funções;<br>
Manipulação de strings;<br>
Entrada e saída de dados (printf, scanf, getchar e fgets).<br>

**Observações**<br>
O ano é informado pelo usuário no início da execução.<br>
As anotações são armazenadas em memória durante a execução do programa.<br>
Ao encerrar o programa, as anotações não são preservadas.<br>

**Futuras melhorias**<br>
Opções de atualizar e deletar anotações;<br>
Tratamento de erros;<br>
Geração de arquivos que exibem o calendário e anotações;<br>
Conexão com banco de dados.<br>

**Como executar**<br>
É necessário ter um compilador da linguagem C instalado. <br>
Clone este repositório:<br>
`git clone https://github.com/BiaGraciolli/Calendario-no-console-em-C/`<br>
Compile o arquivo:<br>
`gcc calendario.c -o calendario`<br>
Execute o programa:<br>
**LINUX** <br>
`./calendario` <br>
**Windows** <br>
`.\calendario.exe` <br>

**Projeto desenvolvido para praticar lógica de programação e os principais recursos da linguagem C.**
